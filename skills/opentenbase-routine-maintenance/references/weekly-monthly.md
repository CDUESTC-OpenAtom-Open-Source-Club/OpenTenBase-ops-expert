# 每周和月度运维项

这些任务不一定每天执行，应先确认维护窗口和影响范围。

## 每周建议

- 检查最近一周巡检报告是否有重复告警。
- 检查备份文件是否连续存在。
- 抽查一次备份文件可读性，例如 `pg_restore -l <dump>`。
- 复查磁盘增长趋势。
- 复查数据库大小增长。
- 检查扩展和插件状态，例如 `plugin_ctl list`、`plugin_ctl check <plugin>`。
- 检查慢 SQL 或高频错误日志。

## 每月建议

- 做一次恢复演练，优先恢复到测试库。
- 审计用户、角色和高权限账号。
- 复查备份保留策略。
- 复查插件清单和无用插件。
- 复查表分布键、数据倾斜和大表增长。
- 复查 OpenTenBase 管理工具和配置备份。

## 需要确认后才能执行

以下任务可能改变环境，不能自动执行：

```text
ANALYZE
VACUUM
REINDEX
CREATE INDEX
备份恢复演练
清理日志
清理备份
插件回滚
权限回收
```

Agent 可以生成计划和命令，但必须等待用户确认。
