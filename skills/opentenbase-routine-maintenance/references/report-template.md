```text
   - 当前风险：
   - 下一步：
```

## 状态分类

```text
正常：核心检查均通过。
有风险：存在磁盘、日志、备份或单 CN 异常，但核心服务仍可用。
异常：集群状态、进程、端口或 CN 连接失败。
未完成：缺少权限、缺少运行用户、命令不可用或用户未确认。
```
