## 建议优先级

1. SQL 改写：减少不必要列、提前过滤、避免函数包裹过滤列。
2. 分布式调整：补充分布键条件、调整 Join 顺序、避免大表跨 DN 重分布。
3. 索引建议：只建议能解释收益的索引。
4. 统计信息建议：需要时建议 `ANALYZE`，但等待确认。
5. 表设计建议：分布键、复制表、分区策略，标为高风险变更。


## 风险说明

- `EXPLAIN ANALYZE` 会执行 SQL。
- `ANALYZE` 会更新统计信息。
- `CREATE INDEX` 会消耗 IO、空间和锁资源。
- 修改分布键或表类型通常需要迁移数据，不能作为即时修复。
